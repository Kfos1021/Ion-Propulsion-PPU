1. Project Overview & ScopeObjective: Virtually design a bench-scale ion propulsion Power Processing Unit (PPU) using a $0 toolchain (LTspice, KiCad, C++, Python).  Scope: Covers power electronics topologies, closed-loop regulation, bare-metal C++ firmware sequencing, Python dynamic plant/load modeling, Software-in-the-Loop (SiL) simulation, ground station telemetry dashboard, automated testing, and multi-layer PCB layout.  
2. Spacecraft Power Bus InputNominal Voltage: 24 V DC.  Input Operating Range: 18 V DC to 30 V DC (allows testing for bus transients, undervoltage dips, and overvoltage events).  
3. Output Power ChannelsBeam / Accelerator Supply: Scaled 50–100 V DC output. High-voltage, low-current stage representing ion beam acceleration.  Discharge Supply: Scaled 12–24 V DC output. Low-voltage, medium-current stage simulating plasma ionization.  Neutralizer Supply: Scaled 5–12 V DC output. Low-voltage stage preventing spacecraft differential charging.  Auxiliary / Heater Supply: Scaled 5–12 V DC output. Auxiliary power channel for cathode heating or control logic.  
4. Embedded Controller Requirements (C++)Bare-metal state machine implementing 8 core operational states: OFF, SELF_TEST, PREHEAT, DISCHARGE_START, NEUTRALIZER_START, BEAM_RAMP, THRUST, and SHUTDOWN.  Safety interlocks enforcing valid transition order (e.g., prohibiting Beam output unless Neutralizer and Discharge currents are established).  Real-time monitoring of system voltages, currents, and temperatures.  
5. Protection & Fault Handling CriteriaBeam Overcurrent / Arc: Fast trip and automated retry sequence.  Output Overvoltage & Bus Undervoltage: Immediate shutdown if bus drops below 18 V DC or outputs exceed safe thresholds.  Overtemperature: Emergency safe shutdown triggered if simulated temperature exceeds threshold (e.g., >85°C).  Channel Failure & Timeouts: Immediate state abort if a supply channel fails to strike/ignote within predefined timeout windows.  
6. Telemetry & VerificationIPC interface connecting C++ controller to Python plant simulator.  Ground-station dashboard calculating input power, output power, and estimated PPU efficiency. Automated execution of test suite (Tests 001–010) generating PASS/FAIL telemetry logs and CSV exports.  
7. Physical PCB Requirements (KiCad)Input EMI filtering and surge protection section.  Multi-channel converter layout with physical isolation between high-voltage (50–100 V) traces and low-voltage MCU control lines.  Current/voltage sensing dividers, thermal relief vias, and programming/debug headers.
